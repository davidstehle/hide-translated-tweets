# Hide Translated Tweets
A simple JavaScript snippet that hides non-English tweets in the For You tab on X (formerly Twitter). It removes the irrelevant tweets that have been flooding everyone's feed and restores the algorithm to what it should be — tweets from people you care about and topics that actually interest you.
# Compatibility
Tested on Safari. Compatible with Chrome, Edge, Firefox, and other browsers that support userscript managers.
# Installation
1. Download and install a userscript manager such as [Userscripts](https://github.com/quoid/userscripts).
2. Add `hide-translated-tweets.users.js` to it.
3. Open X and navigate to the For You tab. The script will automatically start filtering tweets.
